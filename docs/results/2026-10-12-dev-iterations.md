# 연습 문제 다듬기 기록

## 0회차(버그 수정, 다듬기 횟수에 넣지 않음)

- 증상: 연습 실행에서 두 도구 설정의 평균 소요 시간이 기준과 같았다(약 20초). 하네스라면 몇 배여야 한다.
- 실행 기록으로 확인: 플러그인·스킬·하위 에이전트는 모두 불러와졌지만, 에이전트가 스킬을 한 번도 호출하지 않고 바로 결과 파일을 썼다.
- 1차 수정: 세션 시작 시 "이 스킬을 쓰라"는 한 줄을 넣는 자동 실행 설정 → 설정은 돌았지만 에이전트가 무시했다.
- 2차 수정: 세션 시작 시 절차 본문 전체를 "반드시 따르라"와 함께 넣는다(`hooks/session-start.sh`). 하네스는 하위 에이전트 4번 호출, 64초로 실제 동작 확인. 생각 절차는 머릿속 절차라 도구 기록에는 드러나지 않는다.
- 교훈: 비대화형 실행에서 "설치된 스킬"은 스스로 쓰이지 않는다. 도구는 세션 시작 주입으로 적용해야 한다.
- 이 수정 전의 도구 설정 결과는 지웠고, 기준(스킬 없음) 결과는 그대로 썼다.

## 1회차 실행 중단(사용량 한도)

- 72개 실행 중 16개가 Claude 주간 사용량 한도("weekly limit, 10월 15일 오전 9시 초기화")로 2초 만에 실패했다. 이 결과로는 채점하지 않는다.
- 함께 드러난 결함: 문제 해결 축은 시작 파일 때문에 실패해도 "결과물 있음"이라 재실행 때 다시 돌지 않았다. 에이전트가 오류로 끝난 샘플은 결과물과 상관없이 다시 돌도록 고쳤다(`test_agent_error_is_retried_even_when_starter_counts_as_output`).
- 한도가 풀리면 같은 명령으로 재개하면 실패한 16개만 다시 돈다.
- 참고(성공한 실행 기준): 평균 소요 시간 기준 23초, 생각 절차 30초, 후보 경쟁 79초.
